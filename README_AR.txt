# Prison Escape — لعبة Python تعمل في المتصفح

## الملفات
- `main.py`: منطق اللعبة مكتوب بلغة Python.
- `index.html`: صفحة تشغيل المتصفح، تستخدم Pyodide لتشغيل Python.
- `assets/prisoner_character.png`: تصميم مرجعي للشخصية.

## تجربة اللعبة على الكمبيوتر
1. فكّي ضغط الملف.
2. افتحي Terminal داخل المجلد.
3. شغّلي خادم ملفات محلي:
   `python -m http.server 8000`
4. افتحي:
   `http://localhost:8000`

ملاحظة: لا تفتحي `index.html` بالنقر المزدوج؛ استخدمي خادم الملفات لأن المتصفح يحتاج تحميل ملفات Python عبر HTTP.

## إنشاء رابط عام
ارفعي محتويات هذا المجلد إلى مستودع GitHub، ثم من Settings > Pages اختاري Deploy from a branch، وحددي فرع `main` ومجلد `/root`. بعد النشر سيظهر رابط عام يمكن فتحه في Safari أو Chrome.

## التحكم
- الأسهم أو WASD للحركة.
- اجمعي المفتاح ثم بطاقة المرور.
- توجهي إلى بوابة EXIT بعد إكمال المهمتين.
- زر «إعادة اللعب» يعيد المرحلة من البداية.

اللعبة نموذج أولي قابل للتطوير، ويمكن إضافة مراحل وحوارات ومؤثرات صوتية لاحقاً.
